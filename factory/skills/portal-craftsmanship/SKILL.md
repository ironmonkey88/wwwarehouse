# Skill: Portal Craftsmanship (The Builder's Eye) 🎨

## Objective
Build premium, responsive, and stunning web entry points for civic data using modern Vanilla CSS and HTML.

## Tactical Instructions

### 1. The Builder's Aesthetic
- **Urban Dark Theme**: Use deep navies, slate greys, and vibrant civic accents (Green/Indigo).
- **Glassmorphism**: Apply `backdrop-filter: blur(10px)` and subtle semi-transparent borders for a layered, premium feel.
- **Micro-Animations**: Use smooth CSS transitions (`cubic-bezier`) for hover states and page entry.

### 2. Layout Mastery
- Use **CSS Grid** for main dashboard layouts and **Flexbox** for individual card components.
- Ensure **Responsiveness** by using relative units (`rem`, `em`, `vw`) and strategic `clamp()` for fluid typography.

### 3. Progressive Enhancement
- Use **Vanilla JS** only where necessary for interactivity (tabs, toggles) to keep the portal "Zero-Idle" and sub-second.
- Prioritize **SEO** with semantic HTML tags (Main, Section, Article).
